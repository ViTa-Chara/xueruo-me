# 《抽帧图书馆》

## Logline
地下「抽帧图书馆」把人生录像截成色调帧做壁纸；管理员薛若米式的观察者发现：有些帧能传染视野缺陷（近视、散光、隧道视）。当 infinity 档案柜要求收录「一切做过的事」，而城市开始把人的未来提前抽成可替换壁纸时，必须决定——谁有权决定别人看见什么。

## Theme question
若人生可被抽成最优帧，真实的模糊是否仍有价值？

## 主线脊椎（刘慈欣式因果机器）
- **起**：建立硬设定——抽帧规则、色调索引、多屏拼接、网格房间入口。主角「观」是底层整理员；访客「林可」要找回被删的一帧；系统「Infinity」默默归档。
- **承**：视野缺陷帧扩散；公司订制「幸福壁纸」；XirNoRi 网格房是隔离舱。观被迫参与一次大规模抽帧，发现自己的过去也被制档。
- **转**：中点——抽帧并非保存，而是用平均色调替换记忆；图书馆的真正产品是「可消费的人生」。林可的关键帧是未优化的失败之日。观的眼睛开始被改写。
- **合**：观选择释放「未抽帧」的原始流（嘈杂、失败、散光式重叠），让城市短暂看见未优化的真实；付出代价是自己部分清晰视觉。余波：图书馆仍在，但多了一条「不可抽」禁区。

## 人物弧
- **观**：谎言「整理帧是中立的」→ 弧：承认观看即权力，选择站在模糊一侧。
- **林可**：谎言「找回那一帧就能回到从前」→ 弧：接受缺失，把失败之日活成现在。
- **Infinity**：系统意志；不是邪魅反派，而是完备归档的冷酷理性。

## 日常/质感
地下湿冷、灯管频闪、纸质索引导卡、手写色号、泡茶、擦镜片、地铁壁纸广告、雨滴在眼镜上的折射。
