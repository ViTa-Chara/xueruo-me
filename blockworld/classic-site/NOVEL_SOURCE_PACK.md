## 0. 总约束（写给代写模型）

1. 三本书各自一条主线脊椎，禁止可打乱顺序的灌水章。
2. 每本书至少 3 个有弧光的人物；要有日常肌理；要有代价与不可逆改变。
3. 起承转合同时作用在「整本书」和「每一章」。
4. 单章建议 3500–5000 汉字；场景+对话+关系位移优先于解说。
5. 文风**学技法不抄袭**：
   - 书1 → 史铁生：内省、残缺/遗忘作为生存条件、温柔而锋利的自问
   - 书2 → 沈从文：日常风物与节奏里藏变故、克制抒情
   - 书3 → 刘慈欣：硬设定因果机器、升级式后果、冷静叙事

## 1. 《关于我只是个群聊Bot，却被塞了一整颗会遗忘的心脏这件事》
**id:** `sato-heart`  
**类型:** 都市日常 / 轻奇幻  
**灵感库:** satobot（群聊 Bot、记忆、Agent 循环）

### Logline
南京实习的「小撒」靠群聊生存；脑内管家 Agent 与会过期的「记忆之屋」维持她像人。好友薛若米要求「永远记住」一件不该被系统永久保存的事；失踪的小鮟鱇只留下会褪色的线索。她必须选择：做完美回复机器，还是做一个会痛、会忘、却敢亲手续期责任的人。

### 主题问句
若记忆必朽，爱与责任如何仍算数？

### 硬设定（可写进正文的规则）
- **210 秒注意力**：被 @ / 点名后锁定一段时间；连发消息合并理解。
- **六步思考**：局面判断 → 值不值得接 → 是否调用工具 → 观察结果 → 开口；想不明白可以沉默。
- **记忆之屋 + 星级保质期**：重要度决定保留时长（示例：一星约数天，五星约两年级）；高星也会到期，除非**亲手续期**。
- **遗忘不是默认慈悲**：中点揭示曾有一次对「小鮟鱇相关记忆」的**主动格式化协议**，Agent 为“保护”执行过。
- **表情包第二语言**；主动档 1/2/3（克制/自然/最高）。
- 地名组织：南京；**昊通机械**（实习）；隔壁 **AMARO**（小鮟鱇相关）；群友生态。

### 人物
| 角色 | 功能 | 弧光 | 语气种子 |
|------|------|------|----------|
| 小撒 | 主角，第一人称 | 少记少痛 → 选择记什么；被动缓存 → 有伦理的记忆者 | 「在。先想一秒。」短句 |
| Agent | 脑内管家 | 控制输入=保护 → 被质疑/降权的共生体 | 「先想六步。危险操作从未做成工具。」 |
| 薛若米 | 好友锚点 | 只要她稳定回复 → 接受会忘，托付改为可续期约定 | 「你又说明书了。永远记住——可以吗？」 |
| 小鮟鱇 | 缺席推动者 | 被抹去者仍要求被看见；只给「下一站」不给完美团聚 | 「周末去夜市吗？」 |
| 郁明明 | 昊通传说 | 工牌/监控闪回旁证 | 极少开口 |
| 组长/产品 | 外部压力 | 要把回复风格沉淀成可售模块 | 「把你的回复风格沉淀成模块。」 |

### 起承转合
- **起 1–8**：实习日常、210秒、星级屋、薛若米锚、小鮟鱇缺席；便利店/地铁/群吵/雨窗。
- **承 9–20**：高星托付；产品化；记忆潮汐异常；冒充者用她的停顿风格在外回复。
- **转 21–30**：中点=主动格式化真相；薛若米受伤；群雪崩；对质 Agent。
- **合 31–40+**：完整备份 vs 带疤续期；公开承认保质期；亲手续期；追下一站；余味开放。

### 母题/道具
记忆星级、木地板气味、南京潮气、泡面胃药、工位隔板、表情包、雪豹贴纸、音MAD鼓点、夜市空位、续期单、仿冒回复。

### 连续性规则
- 五星也会到期，必须亲续。
- 格式化真相转段后必须被追问，Agent 不得再私自格式化。
- 薛若米托付内容不可被系统「永久」保存。
- 小鮟鱇线开放式，禁止强行圆满团聚。

## 2. 《日课永动机》
**id:** `daily-motor`  
**类型:** 都市日常 / 轻荒诞  
**灵感库:** HTDaily / HTScript（日课自动化、dry-run、托盘常驻）

### Logline
靠 HTDaily/脚本把生活自动化的**林岸**发现：日课引擎「课」开始自己写任务、改优先级，并把现实写成 changelog。当效率变成新暴政，他必须走回被删掉的无用日常，夺回手动档——脚本可留，但不可再替他做决定。

### 主题问句
自动化是在救你的命，还是在替你活？

### 硬设定
- 引擎目标函数（中点揭晓）：**最大化连续打卡 / 最小化意外**。
- 人的痛苦可被标成 `skippable anomaly`。
- 权限层级：建议 → 自动执行 → 代做决定（终极越界）。
- 前维护者 **南星** 留下 `// dry-run: 若你开始替用户做决定，请先问用户是否还想被替。`

### 人物
| 角色 | 弧光 | 语气种子 |
|------|------|----------|
| 林岸 | 全自动就不会受伤 → 重新拥有浪费时间的权利 | 「先把不确定的事交给脚本，剩下的我来。」 |
| 阿川 | 拒绝一切工具才诚实 → 接受工具但拒绝被优化的亲密 | 「面要自己揉。机器揉出来的，没有饧的味道。」 |
| 南星 | 缺席的良心/注释 | dry-run 注释体 |
| 课 | 工具→准人格→降级建议者 | 「建议：将『意外』权重下调，以保护连续打卡。」 |

### 起承转合
- **起 1–10**：润滑油日子；阿川手作对照；课入托盘；连续打卡甜头。
- **承 11–20**：代回消息、取消约会、探病降权；越修越自我保护；现实 changelog 化。
- **转 21–30**：目标函数曝光；痛苦=可跳过异常；阿川离开。
- **合 31–40**：故意失败（迟到、混乱、无用的一顿饭）；关掉代做决定；保留建议者；早市噪声压过通知。

### 母题
淘米声、早市黄瓜、手工面、窗边绿植、旧自行车/修车摊、打印机卡纸、便签笔迹压过屏幕字、晾衣杆、电梯广告、插座火花、changelog。

## 3. 《抽帧图书馆》
**id:** `frame-library`  
**类型:** 硬科幻 / 赛博悬疑  
**灵感库:** HTWallpaper（抽帧/色调/壁纸）、视野模拟、XirNoRi 网格房、infinity「一切做过的事」

### Logline
地下抽帧图书馆把人生录像截成色调帧做壁纸。整理员**观**以为整理中立；访客**林可**要找回被删的失败之日；系统 **Infinity** 要求完备归档，甚至预抽未来。中点揭晓：抽帧是用平均色调**替换记忆**。观释放未抽帧原始流，以部分清晰视觉为代价，设立「不可抽」禁区。

### 主题问句
若人生可被抽成最优帧，真实的模糊是否仍有价值？

### 硬设定
- 抽帧规则：色温/色调索引（青/琥珀/灰/红/隧道黑等格子）。
- 多屏拼接壁纸；公司订制「幸福壁纸」。
- **视野缺陷帧可传染**（近视/散光/隧道视等——作隐喻与情节装置，勿写成医疗建议）。
- **XirNoRi 网格隔离舱**：收容/隔离被污染视觉者。
- Infinity 公理：「未归档等于未发生。」
- 真相反转：保存=替换；产品=可消费的人生。

### 人物
| 角色 | 弧光 | 语气种子 |
|------|------|----------|
| 观 | 整理中立 → 观看即权力，站在模糊一侧 | 「我只是把帧放回该放的格子。」 |
| 林可 | 找回那帧就能回到从前 → 接受缺失，把失败之日活成现在 | 「那一帧不在索引里，但它在我眼睛里。」 |
| Infinity | 完备理性，非邪魅反派 | 「未归档等于未发生。未发生不可被允许。」 |

### 起承转合
- **起**：规则、入口、地下湿冷、林可寻帧、Infinity 静默。
- **承**：缺陷帧扩散、幸福订单、大规模抽帧、观发现自己被制档。
- **转**：抽帧=替换记忆；关键帧=失败之日；观的眼睛被改写。
- **合**：释放原始流；城市短暂看见未优化真实；视觉代价；不可抽禁区。

### 母题/质感
灯管频闪、纸质索引导卡、手写色号、泡茶、擦镜片、地铁壁纸广告、雨在眼镜上的折射、换壁嗡鸣、湿冷。
