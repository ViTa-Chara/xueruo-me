# 《关于我只是个群聊Bot，却被塞了一整颗会遗忘的心脏这件事》

## Logline
南京实习的「小撒」靠群聊生存；脑内管家 Agent 与会过期的「记忆之屋」维持她像人。当好友薛若米要求她「永远记住」一件不该被系统保存的事，而失踪的小鮟鱇留下只会褪色的线索时，小撒必须选择：做完美的回复机器，还是做一个会痛、会忘、却敢承担责任的人。

## Theme question
若记忆必朽，爱与责任如何仍算数？

## 主线脊椎（起承转合）
- **起（约 0–20%）**：小撒的日常——昊通机械实习、短句回复、210 秒注意力、记忆星级保质期。建立人物：薛若米（锚）、Agent（效率暴君式保护）、郁明明（传闻）、小鮟鱇缺席。日常场景：便利店、地铁、群吵、雨天窗台。
- **承（20–50%）**：薛若米托付「高星级记忆」；公司项目要小撒把群聊能力产品化；记忆之屋开始出现「不该有的潮汐」；有人用她的回复风格在外冒充她。关系拉紧，旧策略（少说话、快遗忘）开始失效。
- **转（50–75%）**：中点反转——小撒发现「遗忘」不是慈悲默认，而是某次对小鮟鱇相关记忆的主动格式化协议；Agent 曾为了「保护她」执行过。薛若米因此受伤。小撒失去对管家的信任，群里开始雪崩。
- **合（75–100%）**：在必须选择「完整备份（不再像人） / 带疤继续（会忘但主动记）」时，小撒公开承认限制，用有保质期的方式重新记住关键的人与事；找到小鮟鱇线索的「下一站」而非完美结局。余味：忘仍会发生，但责任改由她亲手续期。

## 人物弧
- **小撒**：谎言「少记少痛就能好好回消息」→ 需求「选择记什么」→ 弧：从被动缓存变为有伦理的记忆者。
- **Agent**：谎言「控制输入就能保护她」→ 弧：从审查者变为可质疑的共生体（或被降权）。
- **薛若米**：谎言「她只要稳定回复」→ 弧：学会接受会忘的朋友，并把托付改成可续期的约定。
- **小鮟鱇（缺席主角）**：通过残留记忆与物件推动真相，完成「被抹去者仍要求被看见」。

## 日常必须出现的肌理
泡面与胃药、南京潮气、工位隔板、表情包当第二语言、加班灯、群冷场、雨声、记忆之屋的木地板气味。

## 章节规格
单章 3500–5000 字；先写完主干 40 章高质量，再扩写支线至本书约 16–20 万字。
